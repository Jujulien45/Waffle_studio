## Keys:

ZQSD for movement

Space bar for jump

Space bar for double jump

E for dash

CTRL in the air for the ground-pound (dash down)

P for the t pause menu



## Movement Mecanics:

- rolling with inertia

- ground pound to break wooden platforms

- dash

- double jump
